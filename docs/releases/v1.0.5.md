## 桌面版 v1.0.5

- 客户端改用 Cloudflare Pages API。Embeat 播放可在同一首歌的代理连接失败时尝试访客网络；Embeat 不可用时，搜索自动回退到网易云。
- 同步近期播放器更新：切歌、最近播放、全屏封面按歌曲来源识别；减少空闲动效与封面加载开销。
- 修复桌面安装包缺少默认封面占位图的问题。

### 选择安装包

| 系统 | 文件 |
| --- | --- |
| Apple Silicon · macOS 12+ | `TY.Music_1.0.5_aarch64.dmg` |
| Windows 10/11 x64 | `TY.Music_1.0.5_x64-setup.exe`（常规安装）或 `TY.Music_1.0.5_x64_en-US.msi` |

安装包未做正式公证或 Authenticode 签名；升级前可在「关于 → 个人曲库备份与迁移」导出备份。在线歌曲的可用性取决于访问网络和音源。
